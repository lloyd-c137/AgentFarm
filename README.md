# Agent Farm

把交给 AI 的任务，种成一片田。

Agent Farm 是一个像素风的游戏化工作台：你把任务派给 ChatGPT、Codex、Claude 这些 AI 之后，每个任务都会变成田里的一株作物。AI 在干活时作物慢慢长；AI 做完一轮、等你回复或授权时，作物头上会冒出气泡；出错会枯萎，失联会落乌鸦；任务完成就自动收获、送进出货箱。这样你同时开很多个 AI 线程时，也不会忘了哪个还在等你。

> 目前页面里是示例数据，每隔几秒自动演示一个事件。所有玩法只用来装扮和放松，不会改变任务状态。

## 运行

单个文件，不需要构建。直接用浏览器打开 `index.html` 即可，进度（金币、装饰、宠物、衣服、矿洞）保存在浏览器的 localStorage 里。

## 玩法一览

- **农场**：地图比屏幕大，镜头跟着农夫走；分为家园、菜田、池塘、鸡舍、山坡矿洞和通往机场的大路几块区域。菜田按来源（Codex、Claude Code、Claude 聊天、其他）分垄，最多 32 个任务；点作物看任务详情，委托板列出所有在等你的任务，不在画面里的待办会在屏幕边缘出现指路牌。天气、昼夜、四季（按 Y 预览）都会变化。
- **小屋与卧室**：走到门口就能进出；家具大多可以互动，椅子和沙发能坐，床能睡觉，衣柜能用金币买衣服（衬衫、卫衣、毛衣、羽绒服、牛仔夹克等）、换发色和肤色。
- **池塘**：走进去会游泳，农夫会自己来回游。
- **矿洞**：横版视角挖矿，按住左键挖，B 建造家具搭地下小窝，X 让农夫自动探索，L 放伸缩梯爬回去，R 魔镜回入口；矿石出洞自动卖成金币。
- **宠物**：在宠物屋领养小狗或小猫，它会跟着你，有任务冒泡时先跑过去叫你；按 P 打开宠物面板。
- **商店**：B 打开，分常用、花园、万圣节、圣诞节、节庆五类装饰。
- **出门旅行**：开小货车去机场，在出发牌或舷梯前选目的地，三座城市各有自己的家、过场、窗景和背景音乐：
  - **伦敦 · 圣诞**：乔治亚风客厅，壁炉、圣诞树、钢琴都能玩；坐到窗边看下雪的伦敦街景。
  - **纽约 · 不夜城**：时代广场边的大平层：整面全景落地玻璃下，左边是开放厨房和大理石中岛、六人餐桌，中间是大沙发围着的客厅，窗边有三角钢琴，右边是书房角，门口是玄关；坐黄色出租车穿过曼哈顿。窗外照着真实的时代广场复刻：从达菲广场高处往南看领结形的广场，尽头是挂着水晶球、贴满屏幕和新闻跑马灯的一号时代广场，近处是坐满人的红色玻璃台阶和达菲神父、科汉的铜像，两侧有弧形的行情塔、弧形红色饮料广告、层层股票跑马灯、巨幅竖屏、剧院海报和警察岗亭的霓虹，街上是黄色出租车、双层观光巴士和警车（广告都是虚构的，没有真实品牌）。配一首原创摇摆爵士。
  - **塞勒姆 · 万圣节**：号称「万圣节之都」的女巫小镇。殖民时期的木构老屋，大壁炉里挂着坩埚，陡楼梯、落地钟、水晶球、漂浮的蜡烛和地上的薄雾；窗外是万圣节夜的街道、南瓜灯、穿着戏服的游人和无人机灯光秀。配一首原创 6/8 拍的诡异华尔兹。
  - 每座城市每天有一份小礼物（衣服或金币），开车、飞行和坐车的路上都能看窗外的风景。
- **H** 查看完整图例和操作，**M** 开关音乐和音效（每个场景有各自的背景音乐和环境声）。
