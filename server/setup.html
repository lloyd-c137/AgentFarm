2 · 把 AI 工具接进来

  1. 点「复制提示词」。
  2. 打开 Claude Code（在哪个项目里都行），粘贴发送。它会自己备份并修改 ~/.claude/settings.json，再发一条测试事件确认连上了；请求改文件时选同意。
  3. 新开一个 Claude Code 会话，发一句话，农场里就会冒出一株新苗。

这些 hook 只上报，不替你做任何决定：服务器总是回空的 200，授权弹窗照常出现；服务器连不上时 Claude Code 也照常工作。
